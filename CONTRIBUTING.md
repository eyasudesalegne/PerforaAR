# Contributing

PerforaAR welcomes reproducible engineering and scientific contributions.

1. Open an issue describing the problem, evidence, and proposed acceptance criteria.
2. Create a focused branch and keep patient or identifiable data outside the repository.
3. Add tests for quantitative behavior and run `pytest` and `ruff check .`.
4. Submit a pull request that states what changed, how it was tested, and which limitations remain.

Do not submit clinical images, names, dates, device identifiers, DICOM headers, access tokens, or data without documented permission and an appropriate license. Changes that affect registration, scoring, or visualization must state the coordinate frame, units, expected error, and failure behavior.
